# Global Public Health & Demographic Storytelling Dashboard

**Role:** BI & Data Visualization Analyst

## 📌 System Scope
Conducted an end-to-end exploratory and comparative analysis of global public health, demographic, and economic indicators across **260+ countries and territories** to uncover cross-national disparities in life expectancy, infant mortality, and HIV/AIDS prevalence.

## 🛠️ Technical Implementation
- Cleaned and structured multi-dimensional country metrics.
- Built **5 distinct analytical views**:
  - Geographical Map
  - Multi-Metric Heat Map
  - HIV/AIDS & Population Tree Map
  - Health vs. Mortality Scatter Plot
  - Life Expectancy Ranking Trend
- Configured interactive **Dashboard Filter** and **Highlight** actions alongside a **4-point executive Tableau Story**.

## 🧩 Tech Stack
- **Tableau**
- **Data Visualization**
- **Data Storytelling**
- **Interactive Dashboard Actions**
- **Exploratory Data Analysis**
